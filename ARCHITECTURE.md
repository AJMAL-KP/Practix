# Practix — System Architecture

Practix is designed with a strict separation of concerns, ensuring game logic, arithmetic, geometry, path validation, and timers are 100% decoupled from browser DOM rendering. This enables fast, deterministic testing via Vitest and seamless, responsive UI rendering.

## Key Architecture Guarantees

1. **No External Framework Bloat**:
   - Built with lightweight, modern TypeScript and Semantic HTML/CSS.
   - Zero heavyweight runtime dependencies (no React or Vue), ensuring sub-second load times and high 60fps mobile responsiveness.
2. **Reliable Exact Decimal Arithmetic**:
   - `ExactDecimal` class handles addition, subtraction, multiplication with exact decimal scale. No `0.1 + 0.2 === 0.30000000000000004` floating-point traps.
3. **Monotonic Timing & Background Handling**:
   - Timers do not rely on `setInterval(..., 1000)` ticks which drift or freeze in background tabs.
   - Remaining time is always computed as `Math.max(0, deadline - performance.now())`.
   - Tab visibility changes (`visibilitychange` event) trigger instantaneous synchronization and timeout checks.
4. **Deterministic Puzzles & Bounded Generation**:
   - Every level generated by Rotate the Path or Invisible Walls is verified by an automated solver before presentation.
   - Generation uses bounded attempts with deterministic fallbacks to guarantee instant load times and zero infinite loops.
5. **Synthesized Web Audio API**:
   - No external `.mp3` or `.wav` files to download or fail loading.
   - Audio synthesized on the fly via `AudioContext` with master volume and persistent mute toggle.
